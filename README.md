🔧 PataFundi

«Find the Right Fundi. Get the Job Done.»

PataFundi is a modern, accessible and intelligent skilled-service marketplace designed to connect customers with reliable fundis in a simple, fast, transparent and trustworthy way.

The platform is designed not only to connect customers and fundis, but also to address common failures found in existing service platforms, including:

- Difficult fundi discovery.
- Poor service-provider verification.
- Unclear availability.
- Lack of pricing transparency.
- Poor communication.
- Complicated booking processes.
- Weak service tracking.
- Low accountability.
- Poor accessibility.
- Complex user interfaces.
- Slow or data-heavy experiences.

PataFundi aims to provide a smooth digital experience that can be used by everyone regardless of their level of digital literacy.

❗ Problem Statement

Finding a reliable fundi can be difficult, especially when customers have limited information about available service providers.

Common problems include:

Customer Problems

- Difficult to find qualified fundis.
- No reliable way to compare fundis.
- Unclear fundi availability.
- Unclear pricing.
- Lack of verified profiles.
- Poor communication.
- Complicated booking processes.
- No proper service tracking.
- Difficulty resolving disputes.
- Poor visibility of previous work.
- Platforms that are difficult for less tech-savvy users.
- High data usage and slow loading on poor networks.

Fundi Problems

- Difficulty finding new customers.
- Limited online visibility.
- Lack of professional digital profiles.
- Poor tools for managing requests.
- Poor booking management.
- Lack of reputation-building mechanisms.
- Difficulty communicating with customers.
- Limited access to digital opportunities.

🎨 Design Principles

PataFundi follows several core design principles.

1. Simple

Users should understand what to do without training.

2. Fast

The platform should respond quickly and minimize unnecessary operations.

3. Accessible

People with different technical abilities should be able to use it.

4. Mobile First

The interface will prioritize smartphone users.

5. Trustworthy

Users should have enough information to make informed decisions.

6. Transparent

Important information such as service details, booking status and pricing should be clear.

7. Inclusive

The platform should not assume that every user is highly familiar with technology.

⚙️ Installation

Clone repository:

git clone <YOUR_REPOSITORY_URL>
cd PATAFUNDI

Go to backend:

cd backend

Create virtual environment:

python -m venv .venv

Windows:

.venv\Scripts\Activate.ps1

Linux/macOS:

source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt

---

🗄️ PostgreSQL Setup

Create database:

CREATE DATABASE patafundi;

Configure connection:

DATABASE_URL=postgresql+psycopg://username:password@localhost:5432/patafundi

---

🔐 Environment Variables

Create:

.env

Example:

APP_NAME=PataFundi
ENVIRONMENT=development

DATABASE_URL=postgresql+psycopg://username:password@localhost:5432/patafundi

SECRET_KEY=change-this-secret
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

CORS_ORIGINS=http://localhost:3000

Never commit ".env".

🗃️ Database Migration

Initialize Alembic:

alembic init alembic

Create migration:

alembic revision --autogenerate -m "create initial tables"

Apply:

alembic upgrade head

Rollback:

alembic downgrade -1
